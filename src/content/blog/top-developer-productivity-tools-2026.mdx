## 1. Raycast: The Keyboard-First OS Supercharger

If you are still using default macOS Spotlight or Alfred with outdated plugins, **Raycast** is an immediate upgrade. Written natively in Swift, Raycast launches in under 10 milliseconds and consumes negligible background RAM.

### Why Developers Swear By It:
* **Clipboard History**: Search past code snippets, passwords, and JSON payloads with instant fuzzy matching.
* **Window Management**: Tile and arrange multiple IDE and terminal windows instantly using hotkeys (`Cmd + Option + Left/Right`).
* **Developer Extensions**: Run cURL commands, generate UUIDs, encode base64 strings, and inspect GitHub PR statuses directly from the search bar.

## 2. Bruno: The Lightweight, Git-Friendly API Client

For years, Postman was the undisputed champion of API testing. However, bloated electron runtimes and mandatory cloud sync prompted a massive developer backlash.

**Bruno** is an open-source API client that stores your API collections directly as plain-text `.bru` files in your git repository:
* Version control your API requests alongside your backend codebase
* Zero cloud lock-in or forced login screens
* Runs locally with instant startup times

---

## 3. Linear: Software Issue Tracking at the Speed of Thought

Nothing kills engineering momentum quite like waiting 4 seconds for a Jira ticket modal to render. **Linear** is built around keyboard shortcuts (`Cmd + K`, `C` to create, `M` to move).

* **Automatic Git Branch Integration**: When you assign yourself an issue, Linear copies the exact `git checkout -b username/ENG-102-fix-auth` command to your clipboard.
* **PR Auto-Closing**: Merging your GitHub pull request automatically transitions tickets to Done and alerts your team.
